# Local artifact petitions

`Generator::petition_artifact` queues an existing claimant's request at the
object's local office. Supported remedies are negotiated return, compensation
paid by an institutional owner, and an explicitly unresolved case. The original
owner, claimant, jurisdiction, proposed terms and consents are recorded.

Respond hears at most one case per office per month, using 0.05 months within
already-completed named office service. Without service the case waits, expiring
unresolved after twelve months. Requests made at a completed boundary cannot use
that same month's work. This is a bounded use of office attendance, not an extra
labor grant. It does not yet allocate hearing time against individual tax cases.

A settlement requires current access and consent of the owner, custodian and all
recorded claimants. Return changes title and custody, with continuous object
provenance. Compensation consumes the owner's real treasury; individual/community
receipts enter the existing local communal account. Insufficient funds, changed
control, lost access or missing agreement leave title and claims intact. Money is
never minted to close a case. This first version negotiates disputes; it does not
infer criminal guilt or authorize unilateral confiscation.

The petition, outcome, actual payment and causal events persist in governance.
An ordinary title sale remains blocked while unresolved claims exist.
