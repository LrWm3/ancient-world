# Archived designs and legacy guides

These documents preserve earlier intentions and version-specific behavior. They
are not active backlogs or current feature descriptions. Statements such as “not
yet implemented” apply to the original document, not today's repository.

- [Original civilization roadmap](civilizations.md): early milestone sequence;
  implemented portions are summarized in the [current guide](../civilizations.md).
- [Version-one civilization beta](civilization-beta.md): legacy food-proxy behavior
  and original controls; use current system guides for modern worlds.
- [History simulation design menu](history-simulation-considerations.md): exploratory
  proposals, many now partially implemented; retained ideas are not commitments.

Calibration reports remain outside this archive because their measured results and
reproduction details are evidence. Read their revision, scenario and limitations
before treating them as descriptions of current defaults.
